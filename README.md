# BMP Watermark Project

Командный проект по предмету ИСРПО. Программа на C++ для наложения цифрового водяного знака на BMP-изображения.

## Технологии
* C++17
* CMake (система сборки)
* GitHub Actions (CI)

## Команда проекта
* **Студент 1** — Разработка класса `BMP` (чтение/запись файлов).
* **Студент 2** — Реализация алгоритма наложения (смешивания пикселей).
* **Студент 3** — Интеграция, создание `main.cpp`, настройка CI и документации.

## Сборка проекта
Требуется компилятор с поддержкой C++17 (g++ версии 7+).

```bash
# Генерация файлов сборки
cmake -B build

# Компиляция
cmake --build build
