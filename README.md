# BMP Watermark Project

Командный проект по предмету ИСРПО. Программа на C++ для наложения цифрового водяного знака на BMP-изображения.

## Технологии
* C++17
* CMake (система сборки)
* GitHub Actions (CI)

## Команда проекта и распределение ролей
* **Студент 1** — Разработка класса `BMP` (чтение/запись файлов, парсинг заголовков).
* **Студент 2** — Реализация алгоритма наложения (смешивание пикселей, `watermark.cpp`).
* **Студент 3** — Интеграция (`main.cpp`), обработка ошибок, настройка CI (GitHub Actions) и написание документации.

## Как работает алгоритм наложения
Водяной знак накладывается с использованием альфа-смешивания (полупрозрачности). 
Для каждого пикселя вычисляется новый цвет по формуле:
`new_color = orig_color * (1 - alpha) + mark_color * alpha`
По умолчанию коэффициент `alpha` равен `0.4` (40% цвета метки, 60% оригинального изображения). Благодаря этому фон остается видимым, а водяной знак — заметным. Поддерживается наложение со смещением (координаты `offset_x` и `offset_y`).

## Сборка проекта
Требуется компилятор с поддержкой C++17 (g++ версии 7+), а также утилита `cmake`.

```bash
# Генерация файлов сборки
cmake -B build

# Компиляция проекта
cmake --build build
```

## Простой запуск чтения и сохранения BMP

Поддерживаются несжатые 24-битные BMP v3. В текущем `main.cpp` включён пример работы модуля BMP: чтение `original.bmp` и сохранение в `output.bmp` без наложения водяного знака.

Положите свой файл с именем `original.bmp` в корень проекта и выполните команды из этой папки:

```bash
cmake -S . -B build
cmake --build build
./build/watermark
```

В корне появится `output.bmp` с теми же размерами и цветами. Если такой файл уже есть, он будет перезаписан. Аргументы командной строки для этого примера не нужны; при успешном выполнении программа завершается без сообщений, при ошибке выводит её причину.

На macOS открыть исходник и результат можно командой:

```bash
open original.bmp output.bmp
```

Основной сценарий наложения водяного знака сейчас закомментирован в `main.cpp`; его интеграция, настройки запуска и тесты относятся к оставшимся задачам команды.
